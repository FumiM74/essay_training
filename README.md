# 文章の型トレーニング

短い一文から本番形式の小論文まで、文章構成力を段階的に身につけるためのWebアプリです。

文章を書くことが苦手な学習者でも、いきなり長い小論文へ取り組むのではなく、主語と述語、情報の整理、理由、具体例、段落、要約、反対意見への応答という順序で練習できます。提出後はClaudeによる判定と解説を受け取り、必要な箇所を直しながら次の段階を目指します。

> このプロジェクトは開発中です。認証、学習データ保存、Claude添削、問題生成、Cloudflare上の検証環境まで接続済みです。課金、管理者機能、通知、一般公開前の最終検証は未完了です。

## このアプリでできること

- 文章の基礎から小論文まで、14段階のカリキュラムで練習する
- 通常トレーニングで合格を重ね、進級テストに合格して次の段階へ進む
- Claudeから、現在の段階で必要な技能に絞った判定と解説を受け取る
- 要修正の答案を、解説を見ながら同じ問題で書き直す
- 複数問のセットでは、正解済みの問題を残して間違えた問題だけを再提出する
- 長文問題では前の答案を残し、指摘された部分を修正する
- 下書き、提出履歴、進捗を保存し、再読み込み後や別端末でも学習を続ける
- 到達済みの段階へ戻って復習する
- 解説を通常表現またはやさしい表現に設定する
- ランダムな論点、または学習者が設定したテーマで練習する

## 学習の流れ

```text
通常トレーニング
  ↓ 規定数に合格
進級テスト
  ↓ 規定数に合格
次の段階
```

要修正になっても、それまでの合格数は減りません。複数問の問題では正解した小問を保持し、未達の小問だけを直します。長文では毎回ゼロから書き直さず、直前の答案と最優先の修正点を引き継ぎます。

通常トレーニングと進級テストの必要合格数は、学習者が設定画面で変更できます。

## 14段階のカリキュラム

| 段階 | 学習内容 |
|---|---|
| 1 | 文を作る基礎 |
| 2 | 情報を整理して一文を作る |
| 3 | 文と文の論理を組み立てる |
| 4–6 | 意見、理由、具体例を書く |
| 7–8 | 段落を分析し、組み立てる |
| 9 | 要約する |
| 10 | 資料を使って意見を書く |
| 11 | 別の立場を扱う |
| 12 | 構成メモを作る |
| 13 | ミニ小論文を書く |
| 14 | 本番形式の小論文を書く |

## 学習設計の特徴

### 段階に合った添削

後の段階で学ぶ技能を理由に、前の段階の答案を不合格にしない設計です。たとえば一文の基礎を練習している段階では、小論文全体の構成ではなく、その段階で求める技能を中心に判定します。

### 苦手と多様性を考慮した出題

提出履歴から苦手な技能や経験済みの題材を確認し、同じ傾向の問題が続かないように次の問題を選びます。固定問題を使い切った後は、段階の学習目標に沿った問題をClaudeで生成し、機械検査と独立した品質審査を通過した問題だけを表示します。

### 修正する過程も学習にする

要修正の答案は破棄せず、前回の解説と一緒に再表示します。Claudeは、前回指摘した重要な問題が直ったかを先に確認します。修正できた答案へ新しい細かな条件を追加し続け、合格を不必要に先延ばししないようにしています。

## 主な画面

- **ホーム**: 現在の段階、合格数、次の問題を表示
- **課題**: 段階の選択、トレーニング、進級テスト、復習
- **履歴**: 問題、提出した解答、正誤、解説を確認
- **進捗・設定**: 段階別の進捗、必要合格数、解説の難易度、テーマを設定
- **アカウント**: 登録、ログイン、ログアウト、パスワード再設定

## 技術構成

| 領域 | 使用技術 |
|---|---|
| Webアプリ・PWA | SvelteKit、TypeScript、Vite |
| 認証・データベース | Supabase Auth、PostgreSQL、Row Level Security |
| サーバー処理 | Supabase Edge Functions、TypeScript、Deno |
| AI添削・問題生成 | Anthropic Claude API |
| 配信 | Cloudflare Workers、Workers Static Assets |
| テスト | Vitest、Svelte Check、SQLによるRLS・DBテスト |
| 将来の課金 | Stripe |

Claude、Stripe、Supabaseの秘密鍵はブラウザへ置かず、サーバー側で管理します。学習データはRow Level Securityにより、本人のデータだけを読み書きできる構成です。

## ローカルで試す

### 必要な環境

- Node.js 24.19.0
- Corepack
- pnpm 11系

Node.jsのバージョンはリポジトリ直下の`.tool-versions`で固定しています。

### 起動手順

```bash
cd web
corepack enable pnpm
pnpm install --frozen-lockfile
pnpm curriculum:build
pnpm dev
```

ブラウザで`http://localhost:5173/`を開きます。

Supabaseの接続情報を設定しない場合は、ブラウザ内にデータを保存するローカル体験版として動作します。認証やオンライン保存を確認する場合は、`web/.env.example`を参考に`web/.env.local`を作成してください。秘密情報をGitへコミットしないでください。

## 検査

```bash
cd web
pnpm verify
```

このコマンドは、カリキュラムJSONの生成、型検査、自動テスト、QA用テスト、製品ビルドを順に実行します。

SupabaseのDB・RLSテストやCloudflareへの公開には、それぞれのCLIへのログインとプロジェクト接続が必要です。

```text
essay_training_system/
├── web/                    SvelteKit製の学習者向けPWA
├── supabase/               DB migration、RLS、Edge Functions、SQLテスト
├── curriculum-design/      カリキュラムの設計資料
├── tools/qa/               AI生成問題を検証する隔離済みQAツール
```
